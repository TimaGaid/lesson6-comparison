# Порівняння тарифів

Сторінка з невеликою таблицею порівняння трьох вигаданих тарифів. Мета — попрактикувати контентний контейнер, локальні шрифти, нормалізацію CSS та семантичні таблиці. Усі дані умовні.

## Технології

HTML5 та CSS3, без JavaScript і збирача. Таблиця містить `caption`, `thead`, `tbody`, заголовки зі `scope="col"` та `scope="row"`. Контейнер центрований і обмежений до 1000 px. Шрифт Manrope підключений локально у форматі WOFF2 для кирилиці й латиниці; резервні шрифти — Arial та sans-serif. Ліцензія шрифту: `fonts/OFL.txt` (SIL Open Font License).

## Фактична перевірка

Сторінку відкрито й візуально перевірено в Google Chrome 157 на macOS. У DevTools підтверджено завантаження обох локальних файлів Manrope (`loaded`), `body margin: 0`, `box-sizing: border-box`, `border-collapse: collapse`, відступи комірок 18 × 20 px та чергування кольорів рядків. Правила нормалізації базові; їхню точну відповідність матеріалам заняття не перевірено, оскільки конспект не надано.

На ширині 320 px `scrollWidth` дорівнює ширині viewport (320 px), небажаного горизонтального скролу немає; відступи комірок становлять 12 × 7 px. На ширині 1104 px горизонтального переповнення також немає. Для перевірки fallback у DevTools тимчасово встановлено неіснуючу першу гарнітуру перед Arial: сторінка залишилася читабельною, переповнення на 320 px не з'явилося. Ці тимчасові зміни не входять у вихідні файли.

Друге середовище не перевірялося за побажанням автора; порівняння не виконано.
