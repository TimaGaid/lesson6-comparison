# Порівняння тарифів

Сторінка з таблицею порівняння трьох умовних тарифів. Мета — практика семантичних таблиць, локальних шрифтів і базового оформлення сторінки.

## Технології

HTML5, CSS3, локальний WOFF2-шрифт Manrope із системним fallback Arial, sans-serif. Ліцензія шрифту — у `fonts/OFL.txt`.

## Перевірка

Сторінку перевірено в Google Chrome та Safari на macOS. В обох браузерах таблиця, межі, чергування кольорів рядків і центрований контейнер відображаються коректно; помітних відмінностей у вигляді таблиці не виявлено.

У Chrome DevTools перевірено завантаження локальних шрифтів, системний fallback та обчислені стилі. На ширині 320 px горизонтального переповнення не виявлено.
